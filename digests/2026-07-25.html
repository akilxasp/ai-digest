Deep Dive
AGENTS GET WRITE ACCESS
The through-line today is agents graduating from advisors to operators inside the tools people already use: Webflow's MCP 2.0 adds governance so agents can safely edit production sites, Figma closed the Auto Layout gap so agent-generated frames render like real CSS, and Paper just raised $34M building a canvas that is HTML/CSS by default so designers and coding agents work in the same space. Underneath, the infrastructure is catching up to the ambition — Opus 5 ships cheaper and less gated than its predecessor, and AMD/Cerebras are splitting inference workloads to push more tokens per watt, exactly the throughput always-on agentic tools like these will need.

Daily Tip
When you give an agent write access to something production-facing — a live Figma file, a deployed site — set the boundary before the agent touches it, not after: scope exactly what it can edit and require a review step for anything that ships, the way Webflow's new governance layer does by default. And if a model silently falls back to a weaker one on a refused prompt, as Opus 5's new Automatic Fallbacks feature does, treat that response as unverified until you check it yourself.
