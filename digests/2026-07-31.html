Deep Dive
Infrastructure Catches Up To Agents
Every domain moved on the same axis this week: making AI systems easier to run, trust, and build on top of, rather than just bigger. MCP's rewrite trades stateful sessions for a protocol any agent can self-describe against; Kimi K3 arrives as weights anyone can download and modify rather than an API call; Nscale buying Anyscale is a bet that compute-to-inference consolidates the way cloud infrastructure did before it. Design is adjusting to the same shift from its own angle — Nielsen Norman Group's push for machine-readable context files treats AI tools as a new kind of reader that UX now has to design for, not just a shortcut for humans.
