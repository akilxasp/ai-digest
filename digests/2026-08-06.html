Governance Goes Quiet, Tools Get Sturdier
Two of today's biggest AI stories aren't about a new model — they're about who controls the story. Google concentrated its AI leadership away from DeepMind's day-to-day helm, and the White House finished reviewing a frontier-model safety framework with the top labs, then chose to keep its contents private. Meanwhile the tools people actually touch each day shipped dependability fixes, not fanfare: Claude Code closed a subagent isolation gap, GitHub Copilot let developers dial reasoning up or down per task, and Framer added branching to its plugin system. The clearest signal of where this all lands is design — a fresh 900-designer survey found weekly AI use jumped from 54% to 91% in a year, with toolstacks nearly doubling. Adoption is no longer the question; workflow design is.

Daily Tip
When a coding agent lets you set a reasoning level per task, as GitHub Copilot's cloud agent now does, save the highest setting for genuinely hard multi-file problems and drop it for boilerplate or renames — more reasoning burns tokens without making simple work faster. And if you run agents in isolated worktrees, treat that isolation as a boundary worth checking, not a given: keep destructive commands out of any prompt an agent could run unsupervised.
